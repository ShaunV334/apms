# Frontend App (Expo React Native)

This directory contains the APMS-2 caregiver application built with Expo, React Native, and Firebase.

For full repository documentation, setup context, and backend notes, read the root README first.

## What This App Does

The app provides real-time caregiver visibility and workflows:

- Sign-in/sign-up with Firebase Authentication.
- Home dashboard with live vitals and latest fall status.
- Map screen with watch location tracking and editable geofence radius.
- Logs screen with day-grouped medicine and vital summaries.
- Medicine screen for creating and toggling recurring schedules.
- Audio screen for recording and uploading short voice clips to Firestore.
- Profile screen for caregiver details, patient selection, and account sign-out.

## Key Source Areas

- `app/`: Router entry points and app-level composition.
- `components/`: Auth screen and custom tab bar.
- `hooks/`: Firestore subscriptions, auth state, alerts, geofence logic.
- `screens/`: Feature screens rendered in the pager/tab flow.
- `services/`: Notification and user-scoping utility modules.
- `styles/`: Style modules for each screen/component.
- `plugins/withFirebaseAndroid.js`: Generates `google-services.json` from env vars.

## Local Development

### Install

```bash
npm install
```

### Configure environment

```bash
cp .env.example .env
```

Fill all values in `.env`:

- `FIREBASE_PROJECT_NUMBER`
- `FIREBASE_PROJECT_ID`
- `FIREBASE_STORAGE_BUCKET`
- `FIREBASE_MOBILESDK_APP_ID`
- `FIREBASE_ANDROID_PACKAGE_NAME`
- `FIREBASE_API_KEY`

### Run

```bash
npm run start
```

Other scripts:

- `npm run android`
- `npm run ios`
- `npm run web`
- `npm run lint`

## Build Notes

- Android native project is present under `android/`.
- iOS native project is present under `ios/`.
- Firebase Android config can be generated by the Expo plugin at config time.
- Notification and audio flows require native modules and proper device permissions.

## Data and Alerts

Primary collections read/written by frontend hooks:

- `users/{uid}` and nested user collections.
- `vitals`, `falls`, `locations`, `medicineLogs`, `voiceMessages`.

Alert hooks currently cover:

- Vitals thresholds
- Fall detection
- Medicine reminders
- Geofence breach transitions

## Troubleshooting

- Authentication errors: verify Firebase Auth is enabled and API key/project values are correct.
- Firestore permission denied: compare access pattern with `../firestore.rules`.
- Missing map data: confirm watch GPS uploads to `locations` or user-scoped locations.
- Notification issues: ensure notification permissions are granted and native build includes Expo Notifications support.
